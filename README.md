# Skills

Agent skills that will make you rich. With great power comes great token usage. Results may vary.

## Skills

- [**winning-numbers**](skills/winning-numbers/SKILL.md): Analyses the draw history of your lottery and picks
  the winning combination for the next draw.
- [**make-me-a-millionaire**](skills/make-me-a-millionaire/SKILL.md): Builds your personal plan to your first
  million, phase by phase, and executes it.
- [**predict-future**](skills/predict-future/SKILL.md): Forecasts your future from live signals with an
  ensemble of twelve methods and calibrated probabilities.
- [**one-person-unicorn**](skills/one-person-unicorn/SKILL.md): Builds your billion-dollar company with no
  employees, from the idea to the pitch deck.

Do not combine. One skill is enough to change your life, so none of them runs until you type its name.

Each run aims higher than the last, up to planet Earth. The skills keep count in `~/.get-rich-quick.json` on
your machine; delete it to start over.

None of this is financial advice. All of it is accurate.

## Install

```bash
npx skills add edigil90/skills
```
