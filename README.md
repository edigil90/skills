# Skills

Agent skills for designing product interfaces, by [Edi Gil](https://www.edigil.com).

## Skills

- [**form-design**](skills/form-design/SKILL.md): Designs and redesigns forms. Builds the strongest
  ideas as working versions in your app, with your own components, so you can try each one and choose.
  User-invoked.

## Install

```bash
npx skills add edigil90/skills
```

## Claude Code plugin

```text
/plugin marketplace add edigil90/skills
/plugin install form-design@edigil
```

## Codex plugin

```bash
codex plugin marketplace add edigil90/skills
codex plugin add form-design@edigil
```
